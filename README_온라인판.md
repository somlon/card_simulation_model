# NNY 온라인판 (online/main)

세창의 NNY 시뮬레이터 v1.1.0 을 기반으로 한 온라인판 운영 브랜치.
**룰 엔진(nny_sim/*.py 의 게임 규칙)은 이 브랜치에서도 수정하지 않는다** — 수정은
룰미스 메모 → 수정 고리(임시 패치 딱지 + 세창 승인 PR)로만.

## 구조 (사용자용 안내)

| 위치 | 내용 |
|---|---|
| `시작_온라인서버.bat` | **호스트가 더블클릭하는 실행 파일.** 최신 코드로 자동 갱신 후 서버 시작 |
| `온라인_접속_안내.md` | 친구용 접속 방법 (하마치 new_card_game / 17225 / 25.0.242.63) |
| `online_users.json` | 등록 유저(이름↔하마치 IP, 최대 5) |
| `nny_sim/app/` `nny_sim/viewer/` | 서버·화면 소스 (v1.1.0 빌드에서 가져옴 — 온라인 기능이 여기 얹힌다) |
| `nny_sim/online_demos/` | AI 방식 3안 데모 (docs/AI_방식_선택지.md 참조) |
| `재정질문/` | 룰 해석 질문 수집함 |
| `NNY온라인_진행.md` | 루틴 상태 파일 |

## 실행 전제 (호스트 PC)

무거운 것들(파이썬 런타임 · 카드 이미지 · 학습표 · 기본 재생 기록)은 깃에 안 올린다 —
**v1.1.0 zip 이 바탕화면 `NNY_Simulator\` 에 풀려 있어야 하며**, bat 이 그쪽의
`runtime/`·`data/` 를 그대로 쓴다. 코드만 이 브랜치에서 갱신된다.
