# 배포 — 테스터에게 주는 파일의 정본

`뉴네오 듀얼 실행.bat` 하나만 준다(카톡 zip). bat 은 **세 가지만** 한다 —
파이썬 찾기 · 저장소 받기 · `scripts/부트.py` 실행. 갱신·의존성·안내·서버는 전부
부트.py(저장소 쪽)에 있어서 **깃허브에 고치면 테스터가 다음 실행 때 바로 받는다.**
bat 자체를 고칠 일은 "파이썬을 못 찾는다"와 "저장소를 못 받는다" 둘뿐이다.

- bat 은 반드시 **CP949 + CRLF** (2026-10-28 LF 사고 — cmd 가 명령을 잘라 먹음).
- bat 안의 표시 글은 일부러 영문이다 — 코드페이지가 다른 PC(437 등)에서 한글이
  깨져 보이는 것을 피했다. 한글 안내는 부트.py 가 찍는다(파이썬이 콘솔 인코딩을 알아서 맞춘다).
- 수정하면 이 폴더의 정본을 고치고, 바탕화면 사본과 zip 을 다시 만든 뒤
  DuelModel 가지에 미러할 것.
