# 포커짐승들 (POKER BEASTS)

## 개요

- 몬스터의 레벨을 포커 숫자로, 속성을 포커 문양으로 사용하여 족보를 완성시키는 테마
- 성립 족보 6종: 원페어·트리플(올인), 스트레이트·플러쉬·풀 하우스·포카드(각 본체)
- 상대 필드 카드도 족보 재료로 사용 가능 — 대치가 길어질수록 유리
- 신설 개념: 문양 속성 (스페이드 ♠ / 다이아 ◆ / 하트 ♥ / 클로버 ♣)
- 모든 몬스터 종족: 야수족
- 카드군: 「포커짐승들」 20종 (태그 기준) / 「토끼」·「늑대」·「강아지」·「고양이」 각 3종
- 색 분포: 녹 13 / 청 3 / 적 1 / 황 1 / 백 1 / 흑 1

### PKBS-014: 짐승조커

- **카드 종류**: 마법 카드
- **마법 분류**: 신속
- **색**: 녹색
- **태그**: 포커짐승들
- **카드군**: 포커짐승들

**효과**:
1. [신속] 레벨과 속성을 선언한다. 이 카드는 해당 레벨과 속성을 가진 몬스터로 취급되어 원하는 자신 필드에 특수소환한다. (이 효과는 패에서도 발동할 수 있다.)
2. [트리거] 이 카드가 릴리스되었을 때 발동. 이 카드를 덱으로 되돌리고 1장 드로우한다.

**플레이버**: *도둑잡기 시작이다..*

**재정 (Rulings)**:
- 1번으로 몬스터 취급되어 특수소환될 때, 공격력 0 / 수비력 0 · 종족 없음으로 간주한다. 몬스터 존에 놓인다.

### PKBS-015: 포커짐승들의 도박장

- **카드 종류**: 필드 카드
- **색**: 녹색
- **태그**: 포커짐승들
- **카드군**: 포커짐승들

**효과**:
1. [지속] 자신 「포커짐승들」 몬스터의 [신속] 효과를 패에서도 발동할 수 있다. (이 효과는 1턴에 2번까지 사용할 수 있다.)

**플레이버**: *여기서는 아무도 딴 적이 없다고 한다.*

### PKBS-016: 올인

- **카드 종류**: 스킬 카드
- **색**: 녹색
- **태그**: 포커짐승들
- **대응 카드군**: 포커짐승들

**효과**:
1. 자신은 라운드 시작 시의 패를 7장 구성한다.
2. [지속] 자신 필드의 「포커짐승들」 몬스터는 다음의 효과를 얻는다.
   - [신속] 자신을 포함하는 패, 필드의 레벨이 같은 몬스터 2장을 릴리스하고 발동. 상대 필드의 카드 1장을 골라 속성과 레벨을 부여하여 컨트롤을 옮긴다.
   - [신속] 자신의 몬스터를 포함하는 자신 패, 필드, 상대 필드의 같은 레벨의 몬스터 3장을 릴리스하고 발동. 덱에서 6레벨 이하의 「포커짐승들」 몬스터 1장을 소환한다.

**플레이버**: *올인은 패가 좋아서 하는 게 아니다.*

**재정 (Rulings)**:
- 덱 구축은 정본 2를 따른다. 공용 태그 카드를 포함한 공용 카드 10종을 다른 테마와 동일하게 채용할 수 있다.
