# 블록 체계 (조립식 카드 효과)

사용자 지시(2026-10-28): 미뤄 두었던 블록 체계 전체를 구현해 PR. 결정 —
**AI 점수는 B안(블록 가치로 일반화)**, **카드 코드와 텍스트가 어긋나면 텍스트대로 고침**(달라진 곳은 목록으로 보고).
설계 근거: 블록 라이브러리 목록 통합판 27개판(2026-10-28, `docs/block-library`), 조립식 전환 계획(2026-10-25).

## 한눈에

```
카드 텍스트(card_pool.json)
  └─ 효과 문장 (카드 코드 × 효과 번호, 부여 효과는 「-」 항목)
       └─ 문장 틀(조립표, blocks/t_*.py) ── 틀과 문장을 맞춰 수치를 읽는다(틀이 맞지 않으면 테스트 실패)
            └─ 조립 명세 (효과 틀 + 시점 · 조건 · 고르기 · 코스트 · 처리 · [지속] 블록)
                 └─ 조립기(build.py) ── 문장마다 한 번 코드 생성 · 캐시
                      └─ engine.Effect(cond · cost · res · score) / [지속] 훅(rules · flags · atk_mod · on_event …)
```

- 카드마다 효과 함수를 쓰지 않는다. 효과는 블록(종류별 함수, `lib.py`)을 효과 순서대로 조립한다.
- **수치는 텍스트에서 읽는다(R6)**: 조립표는 문장에서 수치 자리만 비운 「문장 틀」이다(`{n}` · `{amt}` …).
  텍스트의 수치가 바뀌면 그대로 따라가고, 문장이 바뀌면 틀이 맞지 않아 `test_blocks`가 실패한다(지문 검사).
- 조립표에 없는 카드는 옛 카드 함수(cards*.py)를 그대로 쓴다 — 옮기는 동안에도 시뮬레이터는 늘 동작한다.
  모든 카드를 옮기면 옛 함수를 지운다.

## 블록 (27개판)

| 분류 | 블록 | lib 함수 |
| --- | --- | --- |
| 발동 시점 | E1 소환되었을 때 · E2 발동했을 때 · E3 카드가 옮겨졌을 때 · E4 시점 · E5 값 변화 · E6 무효화되었을 때 | `when_*` |
| 조건 | C1 조건(집합 × 필터 × 수량 비교) | `cnt` · `cond_*` |
| 고르기 | S1 고르기(카드 · 값 · 선택지, 대상 지정 여부는 필수 값) | `pick` |
| 처리 | A1 파괴 · A2 이동(드로우 · 덱 위 보내기 포함) · A3 릴리스 · A6 특수소환 · A7 마법 놓기 · A8 장착 · A9 필드 안 이동 · A12 발동 무효 · A13 소환 무효 · A14 카드 무효 · A15 효과 변경 · A16 HP 증감 · A17 상태 · 보정 · A18 표시 형식 · A19 카운터 · A22 효과 부여 · A23 승리 | `do_*` |
| 연결 | J1 차례로(「그 후」 · 「…하고」는 앞이 되었을 때만) · J2 분기 | 조립기 |

- 모드: **cost**(코스트 칸 — 지불자 · 배수 · 행동 세금은 엔진 `Game.activate`), **do**(처리), **apply**([지속] 적용).
- 효과 틀(F01 ~ F14): 키워드 · 발동 위치 · 1턴 횟수 · 강제 · 체인 금지 · 무효화 불가 · 단계 제한 · 선언자 · 부속 · 자동 처리 · 소환 절차 —
  문장의 키워드와 단서 괄호에서 읽는다(`text.py`).

## 고른 카드 · 값의 기록 (Link.ctx)

- 발동 시 고른 **대상**(「대상으로 하고」)은 `l.ctx[이름]` — `engine.link_targets`가 대상으로 본다.
- 처리 때 고른 카드(「고르고」 · 「1장을 파괴한다」)와 코스트로 낸 것(「제거한 개수」)은 `l.ctx['refs']` — 대상이 아니다.
- 사건의 카드(「그 카드」 — 트리거)는 `l.ctx['ev']`.

## AI 점수 (B안)

효과 점수 = 시점 보정 × (처리 블록 가치의 합 − 코스트 블록 가치의 합). 블록 가치는 그때의 게임 상태로 계산한다
(파괴: 상대 카드 가치 + / 자신 카드 −, 서치 · 드로우: 패 1장 가치, 특수소환: 나오는 몬스터 가치, 대미지: 상대 HP 대비, 결착이면 크게 …).
위협도(Effect.threat)도 블록에서 정한다. 학습표 AI는 이 점수를 출발값으로 쓴다(재학습 여부는 사용자 결정).

## 옮기는 순서 · 확인

테마마다: 조립표 작성 → 그 테마 테스트 · 전체 테스트 → 스모크(오류 · 안전장치 중단 0) → 텍스트대로 바뀐 곳 목록(`blocks/CHANGES.md`).
순서: 공용 · 격투가(시험) → 번성충 → 세리 → 솔루나 → 소원의 분수 → 저주인형 → 호박옥 → 포커짐승들 → 던전마스터 → 데이터버그 → 옛 함수 삭제 → PR.
