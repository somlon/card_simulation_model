어떻게 학습하나요

「AI 학습」을 켜고 대전하면, 매치가 끝날 때 AI와 내 판단 기록(어떤 상황에서 무엇을 골랐고 그 라운드를 이겼는지)이 학습표에 더해집니다. 프로그램 안에서는 바로 반영되어 다음 대전부터 AI가 그 결과를 씁니다. 기록은 내 컴퓨터의 사용자 폴더에 쌓입니다(인터넷 불필요).

GitHub 반영은 인터넷이 있어야 합니다. 인터넷 없이 GitHub에 즉시 올리는 것은 불가능하므로, 두 가지 방법을 둡니다.

① GitHub에 올리기(아래): 인터넷과 git, GitHub 로그인이 있으면 학습 기록을 저장소의 데이터 브랜치에 올립니다.
② 내보내기: 파일을 만들어 두었다가, GitHub 웹에서 nny_sim/learned/human_games/ 폴더에 올립니다.

저장소에서는 merge_learning.py가 이 기록을 학습표에 합쳐(같은 매치는 한 번만) 다음 학습 · 리그 · 프로그램 빌드에 쓰게 합니다.

🧠 신경망 학습

    
「AI 학습」을 켜고 나 vs AI 대전을 하면 두 자리의 판단(게임 상태 · 고른 후보 · 그 라운드 승패)이 신경망 표본으로 쌓입니다.
      학습은 기본 모델에서 시작해 지금까지 쌓인 표본 전체로 다시 학습하며, 사람 대전 기록이 반영된 내 학습표를 따라가면서 이긴 라운드의 선택을 늘립니다.
      내 컴퓨터 안에서만 돌고(인터넷 불필요), 끝나면 「AI 대전」에서 AI 종류를 신경망 AI로 고르면 내 모델과 대전합니다.
