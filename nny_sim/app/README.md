# 뉴 네오 유희왕 시뮬레이터 — Windows 게임 프로그램 (app)

관전(재생 목록) · 나 vs AI 대전 · 덱 편집 · 학습(사람 대전 · AI끼리)을 하나로 묶은 싱글플레이 프로그램입니다.
엔진은 이 저장소의 시뮬레이터(`model/main`)를 그대로 쓰고, 화면은 로컬 서버(127.0.0.1)가 띄우는 웹 화면(Edge 앱 창)입니다.

## 사용자용

배포 zip(`NNY_Simulator_v<버전>_win64.zip`)을 풀고 `NNY_Simulator.exe` 를 실행합니다. 설명은 zip 안의 `읽어보기.txt`.

- **관전 · 재생 목록**: 기본 제공 AI 대전 녹화(11개 덱 55대진 + 10매치)를 골라 재생 목록을 만들고 이어서 재생(끝나면 다음 · 반복). 새 AI 대전 녹화.
- **AI 대전**: 나 vs AI(학습표 AI) Bo3 — 판단 패널에서 행동 · 대응 · 트리거 · 대상 · 서치 · 카드 고르기 · 멀리건 · 선후공을 고릅니다. AI vs AI 실시간 관전.
  대전 중에는 AI의 패 · 뒷면 카드 · 드로우한 카드 이름 · 판단 줄을 가리고, 끝나면 모두 공개(복기).
- **덱 편집**: 카드 풀(이미지)에서 덱을 짜고 `deck.validate` 규칙 검사 후 저장 → AI 대전 · 녹화에 사용.
- **학습**: 「AI 학습」을 켜고 대전하면(나 vs AI · AI끼리 관전, 녹화는 「학습 데이터로 남기기」), 매치가 끝날 때 AI와 사람의 판단 기록이 학습표에 더해집니다(아래).
  사람 대전 기록은 AI끼리 기록보다 큰 가중치로 학습하고, 「학습 데이터 정리」에서 매치마다 학습 데이터에서 빼거나 다시 넣을 수 있습니다(아래 「학습 데이터 · 가중치 · 정리」).
- **🧠 신경망 학습**(머리 막대 — 홈 화면 포함 모든 화면): 대전(사람 대전 · AI끼리)에서 쌓인 신경망 표본으로 신경망 AI를 내 컴퓨터에서 학습합니다(아래).
  AI 대전의 「AI 종류」를 「신경망 AI」로 고르면 내 모델(없으면 기본 모델)과 대전합니다.

## 신경망 AI · 로컬 신경망 학습

- **신경망**: 저장소의 DRL 배우망(`drl/model.py` — 판단 후보마다 점수를 매기는 구조). 대국은 `drl.agent.DRLAI`
  (학습표 AI의 후보 생성 · 지침은 그대로, 고르기만 신경망). 전략 덱 교체는 학습표 규칙(`match.side_swap`).
- **기본 모델**: `learned/drl/base_v2/model_best.npz`(저장소 data 계열) — 지금 엔진 · 11개 덱에서 학습표를 교사로 모방 학습(3,000매치) + 자기 대국 PPO(`python -m drl.train`, PyTorch).
- **표본**(`nn_samples.py`): 「AI 학습」을 켠 대전(나 vs AI · AI끼리)에서 학습표 판단이 있는 자리(사람 · 학습표 AI · 신경망 AI — 휴리스틱 AI 자리는 없음)의 판단 =
  게임 상태 관측 · 후보 특징 · 고른 후보 · 그 라운드 승패 · 교사 분포(학습 기록이 반영된 로컬 학습표의 후보 값).
  사용자 폴더 `learning/nn/samples/`(매치당 약 15KB) + `index.json`(매치마다 출처 · 매치 키 · 자리별 AI 종류 · 덱 · 승자).
  학습표 기록(판단 키 · 승패)에는 게임 상태가 없어서 신경망 표본은 따로 쌓는다 — 학습표 기록은 교사 분포로 신경망 학습에 들어간다.
- **학습**(`nn_train.py`, numpy만 — 배포본에 PyTorch 없음): 학습할 때마다 기본 모델에서 시작해 쌓인 표본 전체로 다시 학습한다.
  손실 = `C_TEACHER`·KL(교사 ‖ π) + `C_BASE`·KL(기본 모델 ‖ π) − `C_RESULT`·(라운드 승패 ±1)·log π(고른 후보)의 표본 가중 평균(가중치 = 출처별), Adam · 기울기 노름 상한,
  매치 10개 중 1개꼴을 검증용으로 떼어 검증 손실이 가장 낮은 에포크의 가중치를 남긴다. 결과는 `learning/nn/model.npz`(이전 모델은 `backups/`).
  `tests/nn_grad_check.py`: 순전파 = NumpyActor, 역전파 = PyTorch 학습망 자동 미분, 손실 기울기 = 수치 미분.
- **나누기**(「🧠 신경망 학습」 창 아래 — 학습 기록과 같은 두 방법): 「신경망 내보내기」 = 표본(뺀 매치 제외) · 내 모델 · `manifest.json` 을
  사용자 폴더 `export/신경망표본_<컴퓨터>_<시각>.zip` 하나로(GitHub 웹에서 저장소 `nny_sim/learned/drl/human_nn/` 에 올림) ·
  「GitHub에 올리기」 = 앱 전용 clone 에 `nny_sim/learned/drl/human_nn/<컴퓨터>/` 로 넣어 `data/human-nn-<컴퓨터>` 브랜치에 푸시(`session.Store.git_upload`).
  저장소에서는 `merge_nn.py` 가 여러 사람의 표본을 모아(같은 매치 = 같은 표본 파일 이름은 한 번) 기본 모델에서 다시 학습한다(아래).

## 학습 데이터 · 가중치 · 정리 (`learndata.py`)

- **출처**: `human`(나 vs AI) · `ai`(AI끼리 관전 · 녹화). 학습표 기록은 `learning/human_games.jsonl` · `learning/ai_games.jsonl`, 신경망 표본은 `index.json` 의 `source`.
  출처가 없는 예전 기록 · 표본은 사람 대전(예전에는 사람 대전만 기록).
- **가중치**: `HUMAN_WEIGHT`(3) · `AI_WEIGHT`(1) — 학습표에 더할 때(`policy.Table.update` 의 `w` — 대전 중 바로 배우는 갱신 · 기록을 다시 적용할 때 모두),
  신경망 학습 손실(표본 가중치 `sw`), 저장소에서 합칠 때(`merge_learning.py` · `merge_nn.py`) 같은 값을 씁니다.
- **판단 단위 정리**(1.3.2부터): 매치 행의 「판단」에서 그 매치의 학습표 판단(기록의 갱신 하나) · 신경망 판단(표본 하나)을 하나씩, 또는 판단 · 후보 글로 거른 것을 한꺼번에 빼거나 넣는다.
  「보이는 매치에서 이 판단 빼기」는 여러 매치에 걸쳐 같은 글의 판단을 뺀다. `excluded.json` 의 `parts`(매치 키 → 학습표 갱신 번호 · 신경망 표본 번호), 신경망 표본에는 판단 글(`index.json` 의 `decs`)을 남긴다.
- **학습 데이터 리셋**(1.3.3): 맵 형태 변경으로 학습표 · 전략 덱 교체표는 빈 표, 기본 신경망은 초기 가중치(백지)로 다시 시작. 데이터버그 테마(23장)는 고칠 때까지 카드 풀에서 뺐고(177장), 기본 재생 기록은 새 풀 · 백지 AI로 다시 녹화(53매치).
- **매치 키**: 같은 매치의 학습표 기록과 신경망 표본은 같은 `match` 키. 「학습」 화면의 「학습 데이터 정리」에서 출처 · 덱 · AI 종류로 걸러 매치마다(또는 보이는 것 한꺼번에)
  빼거나 다시 넣습니다 → `learning/excluded.json`. 뺀 매치는 학습표 다시 적용 · 신경망 학습 · 내보내기 · GitHub 올리기에서 모두 빠집니다(파일은 지우지 않음).

## 학습 흐름 (대전 → 저장소)

1. **프로그램 안(즉시, 인터넷 불필요)**: 대전 표(`tables.matchup_table`)의 갱신(`policy.Table.update` — L1 · L2 · L0)을 모아
   사용자 폴더 `learning/human_games.jsonl`(사람 대전) · `learning/ai_games.jsonl`(AI끼리)에 매치 1줄로 덧붙입니다(`id` 로 중복 방지, 줄마다 출처 · 매치 키 · AI 종류).
   다음 대전부터 불러올 때 출처별 가중치로 다시 적용됩니다(뺀 매치 제외).
2. **GitHub 반영(인터넷 필요)**: 「학습」 화면의 「GitHub에 올리기」 또는 「대전이 끝날 때마다 자동으로 올리기」 —
   앱 전용 얕은 clone(사용자 폴더 `git/repo`, sparse)에 두 기록을 합친 파일(줄마다 출처, 뺀 매치 제외)을 넣어 `data/human-games-<컴퓨터이름>` 브랜치로 커밋 · 푸시합니다(git · GitHub 로그인 필요).
   인터넷이 없을 때는 실패만 기록하고, 다음에 쌓인 기록을 통째로 다시 올립니다. 「내보내기」한 파일을 GitHub 웹에서 올려도 됩니다.
3. **저장소에서 합치기**: `merge_learning.py --policy <실행 폴더>/learned/policy.json.xz --logs <human_games 폴더>` —
   새 매치만 출처별 가중치로 학습표에 더하고(`learned/human_games_merged.json` 에 합친 id), 그 표로 이어서 학습(`train_table.py`) · 리그 · 프로그램 빌드를 합니다.
4. **신경망 표본 합치기**: `merge_nn.py --sim <실행 폴더> --inputs nny_sim/learned/drl/human_nn --list`(현황) ·
   `… --out <실행 폴더>/learned/drl/human_v1/model_best.npz [--epochs 4]` — 내보낸 zip · 올린 폴더를 함께 읽어 프로그램 안 「신경망 학습」과 같은 학습기로
   기본 모델(`--base`, 기본 base_v2)에서 다시 학습합니다. 평가(학습표 · 휴리스틱 AI 상대) 뒤 data 계열 브랜치에 올리고 `build_windows.py --nn-base` 로 배포본에 넣습니다.

## 개발 · 빌드

```bash
# 대전별 학습표 · 카드 이미지 · 기본 재생 기록
python3 -c "import sys,json,lzma; sys.path.insert(0,'nny_sim/app'); import tables as T; T.split('<sim>/learned/policy.json.xz','<split>', read=lambda p: json.load(lzma.open(p,'rt',encoding='utf-8')))"
python3 nny_sim/app/build_assets.py <cards>
python3 nny_sim/app/make_library.py --sim <sim(전체 표 없는 사본)> --split <split> --out <library> --all-pairs --workers 4
# 개발 실행(리눅스) — <sim> 에 learned/policy.json.xz 가 있으면 import 때 4GB를 읽으므로 그 파일을 뺀 사본을 쓴다
python3 nny_sim/app/main.py --sim <sim> --split <split> --cards <cards> --library <library> --user <사용자 폴더> --port 8765
# Windows 배포본(우분투: gcc-mingw-w64-x86-64 · Pillow)
python3 nny_sim/app/build_windows.py --sim <실행 폴더(전체 표 포함)> --nupkg python.3.13.17.nupkg --numpy-wheel numpy-2.4.6-cp313-cp313-win_amd64.whl --out <out> --split <split> --library <library> [--nn-base <기본 모델.npz>]
```

Windows 파이썬은 NuGet의 파이썬 재단 공식 패키지 [`python`](https://www.nuget.org/packages/python)(3.13.17)을 씁니다(python.org 는 이 개발 환경 네트워크 정책에 막혀 있음).
실행기 `NNY_Simulator.exe` 는 `win/launcher.c` 를 mingw로 만든 것으로, `runtime\pythonw.exe -I -X utf8 app\main.py` 를 띄웁니다.
`wine` 으로 검증할 때는 `LC_ALL=C.UTF-8` 이 필요합니다(로캘이 POSIX면 wine이 한글 파일 이름을 깨뜨림 — 실제 Windows와 무관).

  상대에게 보여 줄 카드 · 뒷면 카드 재배치 · 앞면으로 뒤집을 몬스터 · 덱에서 묘지로 보낼 카드 · 레벨/속성 부여 대상 · [지속] 효과 변경 여부를 사람에게 묻습니다.
  운(주사위 · 상대의 무작위 고르기)과 규칙으로 정해지는 처리, 번식지 서치처럼 행동 판단으로 이미 묻는 것은 그대로입니다.
