# 매치 재생 화면 (viewer)

AI끼리 둔 Bo3 매치를 기록해서, 필드 매트 위에서 카드가 움직이는 모습으로 다시 보는 도구입니다.
결과물은 HTML 파일 하나입니다. 이미지와 기록이 파일 안에 들어 있어서 인터넷 없이 브라우저로 열립니다.

## 만들기

시뮬레이터 실행 폴더(코드 `model/main` + 데이터 `data/main`, workflow.md의 「다시 돌리기」 참고)를 `--sim` 으로 지정합니다.

```bash
python3 nny_sim/viewer/replay.py --sim ../run/nny_sim --a "투기장의 규칙" --b "던전마스터 셔플!" --seed 1 --matches 3 --out 매치재생.html
python3 nny_sim/viewer/replay.py --sim ../run/nny_sim --pair 세제 "소원의 분수" --pair "솔루나 아츠" "투기장의 규칙" --out 대진모음.html
python3 nny_sim/viewer/replay.py --sim ../run/nny_sim --list        # 덱 목록과 카드 이미지 보유 현황
python3 nny_sim/viewer/replay.py --from-json 기록.json --out 매치재생.html   # --save-json 으로 저장해 둔 기록 다시 쓰기
```

- AI: `--ai table`(기본, 학습표 AI — match_sim과 같은 설정. 판단표를 불러오느라 메모리 약 3.9GB, 매치당 약 15초) 또는 `--ai heuristic`.
- 매치 여러 개(`--matches N`): 시드를 1씩 늘리고 1라운드 선공을 번갈아 정합니다. `--pair` 를 여러 번 주면 대진마다 N매치. 화면 위쪽에서 골라 봅니다.

## 화면

- 보드: 업로드한 필드 매트 이미지. P1(자리 0)은 아래쪽, P2(자리 1)는 위쪽(매트의 뒤집힌 쪽)입니다.
  몬스터 · 마법 존, 묘지 · 제외 존, 메인 · 상급 덱, 스킬 존, 필드 존, 공유 존을 매트 칸에 맞춰 놓습니다.
  공유 존 마커는 양면 코인(그 라운드 선공 쪽 = 백, 후공 쪽 = 흑)으로 매트의 주인 토큰 존에 놓이고(처음 놓기 · 뒤집기 연출), 공유 존 칸에도 같은 색 테두리로 소유를 표시합니다.
- 카드: 카드 시트 이미지를 칸마다 잘라 카드 이름에 붙여 씁니다. 이미지가 없는 카드는 카드 데이터(이름 · 종류 · 스탯 · 텍스트)로 같은 크기의 카드를 그립니다.
  뒷면은 업로드한 카드 뒷면 이미지입니다.
- 연출: 발동(청록 테두리) · 체인 처리(금색) · 파괴(흔들림), HP 변화, 단계 표시, 라운드 사이의 전략 덱 교체 · 선후공 선택 안내.
  화살표: 공격(빨강 — 공격 몬스터 → 대상, 직접 공격은 상대 쪽), 효과의 대상(금색 — 발동 · 처리 중인 카드 → 대상), 효과로 고른 카드(하늘색 — 코스트 · 처리 때 고름).
  체인: 화면 오른쪽에 1번(먼저 발동)부터 위에서 아래로, 처리 중인 고리는 금색 · 보드의 카드 위에도 「체인 n」.
- 속도: 1×가 예전보다 약 1.6배 느립니다(기록 줄 사이 · 카드 이동 연출). 0.25× ~ 8×.
- 조작: 재생/정지(Space), 한 단계(←/→), 턴 이동(Shift+←/→), 속도, 위치 막대, 라운드 이동.
  「패 공개」를 끄면 패와 뒷면 카드를 뒷면으로 봅니다. 「AI 판단」을 켜면 AI의 판단 줄(후보별 학습 승률)이 기록에 보이고 재생에도 포함됩니다.
- 기록 줄을 누르면 그 시점으로 이동하고, 카드나 묘지 · 제외 존을 누르면 오른쪽에 크게 보입니다.

## 구성

| 파일 | 내용 |
| --- | --- |
| `record.py` | 기록기. 엔진은 고치지 않고, 기록 줄마다 보드 상태(HP · 패 · 덱 매수 · 존 · 체인(고리마다 대상) · 턴 · 라운드 선공 · 단계)를 찍습니다. 발동 · 공격 · 파괴 · 효과가 고른 카드는 Game 메서드 · `blocks.lib.pick_cards` 를 감싼 관찰 훅이 남깁니다(AI 가치 계산 안의 가정 고르기는 뺌). `check_same` 으로 같은 시드에서 기록기 유무와 상관없이 기록 문장이 같은지 확인합니다. |
| `assets.py` | `assets/src` 의 업로드 원본(매트 · 뒷면 · 카드 시트)을 잘라 data URI로 만듭니다. 시트 격자와 칸 순서의 카드 이름은 `assets/src/sheets.json`. |
| `template.html` | 단일 HTML 껍데기(제목 · 매치 고르기). 보드 · 재생 부품과 스타일은 게임 프로그램과 같은 `../app/static/board.js` · `app.css` 를 `replay.py` 가 그대로 넣습니다(그리기 코드 한 곳). 매트 칸 좌표는 매트 이미지에서 잰 값입니다(칸 중심 x = 160 + 224·열, y = 318 + 304·행, 칸 200×280, 주인 토큰 원 중심 1504, 926). |
| `replay.py` | 명령행 도구: 매치 기록 → 단일 HTML. |

카드 시트를 추가하려면 파일을 `assets/src` 에 넣고 `sheets.json` 에 격자(가로 · 세로 칸 수)와 칸 순서의 카드 이름(카드 풀 표기 그대로)을 적습니다.
시트에 인쇄된 코드는 카드 풀 코드와 다른 테마가 있어(데이터버그 · 번성충 · 호박옥 — 풀 정리 때 번호를 다시 매김) 코드가 아니라 이름으로 잇습니다.
`--list` 가 풀에 없는 시트 이름(오타 확인)과 이미지가 없는 풀 카드를 알려 줍니다. 파일이 없는 시트는 건너뜁니다.
