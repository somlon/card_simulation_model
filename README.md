# card_ai

「뉴 네오」 카드 게임의 대전용 AI. 엔진부터 새로 짠다.

## 목적

- **최종 목표** — 균형 전략 근사까지 (**읽히지 않는 플레이**). 단계와 근거는 [`docs/목표_수준.md`](docs/목표_수준.md)
- **주 용도** — 복기: 「그 시점의 정보로는 A 62% · B 28% · C 10% 가 최선이었다」
- **부 용도** — AI vs AI 자가대전으로 덱 밸런스 측정
- **중점** — 더 나은 판단, 더 정확한 전략 덱 교체, 정보 은닉을 포함한 심리전

## 범위

기존 저장소 `somlon/card_simulation_model` 에서 **카드 데이터만** 가져온다 (`card_pool.json`, 11테마 200장 + 덱 파일).
엔진 · AI는 코드를 공유하지 않고 새로 짠다.

## 구조 (4층)

| 층 | 이름 | 하는 일 | 만드는 방식 |
| --- | --- | --- | --- |
| 0 | 엔진 | 합법수 생성 · 규칙 처리 | 코드 |
| 1 | 마인드맵 | 상황 → 후보 제한 | **덱마다 손으로 작성** |
| 2 | 심리 | 상대의 숨은 패 · 세트 추론 (belief) | 코드 + 자가대전 통계 |
| 3 | 덱 성향 | 공격성 · 리스크 · 자원 관리 | 덱마다 같은 틀의 파라미터 |

1층이 후보를 좁히고, 그 뒤(후보 중 선택 · 상대 모델)를 코드와 학습이 채운다.
마인드맵이 탐색 공간을 줄여 주기 때문에 뒤쪽 학습이 다루는 문제가 작아진다.

## 규칙의 출처와 우선순위

1. **정본 룰지 `뉴 네오 룰지` (2026-10-23 판)** — 상위 정본. 본문 7장 + 부록 2개
2. **재정 문서** (`somlon/card_simulation_model` `docs/main` 의 `재정_질문_2026-10-08_카드.md`, 463줄) — 룰지에 없는 세부를 보충
3. 충돌하면 **룰지가 이긴다.** 단 충돌 건은 `rules/충돌목록.md` 에 적어 두고 사용자 판정을 받는다

재정 문서 상당수는 구 룰지(2026-09-23) 시절 문답이라 새 룰지 본문에 이미 흡수된 것이 섞여 있다.
그런 항목은 충돌이 아니라 중복이므로 룰지 쪽을 쓴다.

## 밸런스 측정 규칙

- 측정할 때는 **학습을 고정(freeze)** 하고 그 버전(모델 해시 · 코드 커밋)을 결과와 함께 기록한다.
  학습이 움직이는 중에 측정하면 수치가 학습 상태를 따라 흔들린다.
- 마인드맵은 덱마다 **같은 기준 · 같은 깊이**로 작성하고, 맵 밀도(노드 수 · 간선 수 · 커버리지)를 덱 간 비교 가능하게 둔다.
  맵 완성도 차이가 승률 차이로 새는 것을 막기 위함이다.
- 맵이 침묵한 상황은 전부 로그로 모은다. 그 빈도순 목록이 다음에 채울 맵 목록이 된다.
- 측정 기준과 게이트 조건은 [`docs/맵_커버리지.md`](docs/맵_커버리지.md) 에 정의했다.
  **덱 간 동등성의 기준은 침묵률이지 노드 수가 아니다.**

## 돌려 보기

```sh
pip install -r requirements.txt     # pyyaml 하나
python scripts/demo_호박옥.py        # 손으로 만든 국면 5개에 호박옥 맵을 돌린다
python tests/test_filter.py         # 32개 테스트 (pytest 없이도 돈다)
```

1층은 **경질 필터**다 — 수를 고르지 않고 거르기만 하며 가중치가 없다. 국면(카드 배치)은 손으로
넣는다. `게임상태.가용수단` 은 일반 소환만 `engine.legalmoves.합법수_생성()` 이 채우고, 나머지
네 동작(발동 · 세금차감 · 표시변경 · 공격선언)은 아직 손으로 넣는다(`engine.legalmoves.커버하지_않음`
참조). 자세한 것은 [`docs/엔진_착수_2026-10-25.md`](docs/엔진_착수_2026-10-25.md).

진행 기록은 [`진행.md`](진행.md) 에 있다.
