## ⚠ 평문(.txt)을 쓸 때 주의

`.txt` 는 원본에서 **기계로 뽑은 것**이라 표 구조가 평탄화되어 있다.
룰지의 전투 계산표 · 부록 표처럼 **표의 행과 열이 중요한 부분은 평문만 보고 판단하면 안 된다.**

표가 걸리는 대목에서는 원본을 직접 파싱할 것:

```bash
# 룰지 (docx) — 표를 행 단위로 읽기
python -c "
import zipfile, re, html
z = zipfile.ZipFile('rules/원본/뉴_네오_룰지_2026-10-23.docx')
xml = z.read('word/document.xml').decode('utf-8')
for tbl in re.findall(r'<w:tbl>.*?</w:tbl>', xml, re.S):
    for tr in re.findall(r'<w:tr[ >].*?</w:tr>', tbl, re.S):
        cells = [html.unescape(''.join(re.findall(r'<w:t[^>]*>(.*?)</w:t>', tc, re.S)))
                 for tc in re.findall(r'<w:tc>.*?</w:tc>', tr, re.S)]
        print(' | '.join(c.strip() for c in cells))
    print('---')
"

# 재정 정리본 (pdf) — PyMuPDF 가 있으면
python -c "
import fitz
d = fitz.open('rules/원본/재정_질문_답변_정리_2026-10-24.pdf')
for i, p in enumerate(d): print(f'===== p.{i+1}'); print(p.get_text())
"
```

평문으로 충분한 대목(서술 문장)은 그대로 써도 된다.
