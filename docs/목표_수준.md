# 목표 수준 — 어디까지 만드는가

사용자 확정 (2026-10-24): **4단계까지 전부.** 두 번째 덱은 **던전마스터 셔플!**

## 1. 단계

| 단계 | 산출물 | 상태 |
| --- | --- | --- |
| 1 | 맵 + 얕은 탐색 → 후보 3개와 각각의 이유 | 설계 중 |
| 2 | belief 계산 → 기댓값 기반 순위 (A · B · C) | 설계 중 (심리 층) |
| 3 | 자가대전 통계로 상대 성향 학습 → 착취적 플레이 | 미착수 |
| 4 | **균형 전략 근사 (CFR류) → 읽히지 않는 플레이** | 미착수 · 최종 목표 |

## 2. 「덱이 몇 개 없으니 정답이 있다」 — 맞다

이 게임은 **2인 제로섬 유한 불완전정보 게임**이다. 미니맥스 정리에 의해 내시 균형이 존재하고,
2인 제로섬에서는 그 값이 유일하며 균형 전략은 **착취 불가능**하다.
즉 「벽을 세우는 게 맞나 공격적으로 가는 게 맞나」에는 **원리적으로 답이 있다.**

다만 답의 모양에 단서가 둘 붙는다. 이걸 모르고 구현하면 엉뚱한 걸 만들게 된다.

### 단서 1 — 정답은 보통 「한 수」가 아니라 「빈도」다

균형 전략은 일반적으로 **혼합 전략**이다. 어떤 국면의 정답은
「벽 70% · 공격 30%」 같은 **확률 분포**로 나온다.

이유는 간단하다. 결정론적으로 두면 상대가 읽고 맞춰 오기 때문에 착취당한다.
정보를 숨기는 것 자체가 가치인 국면에서는 **섞는 것이 최적**이다.

→ **구현상 의미:** AI는 단일 최선수가 아니라 **행동 분포**를 출력해야 한다.
복기 화면도 「A가 최선」이 아니라 **「A 62% · B 28% · C 10%」** 가 정확한 형태다.

단, 모든 국면이 그런 것은 아니다. 한 수가 압도적인 국면에서는 균형도 순수 전략이다
(예: 세금을 못 내 2000 자해가 확정인데 그걸 막는 수가 하나뿐일 때).
**혼합이 필요한 곳은 정보 은닉이 의미 있는 국면뿐**이고, 그 지점을 찾아내는 것이 4단계의 일이다.

### 단서 2 — 정답은 매치업마다 다르다

11덱이면 매치업이 66가지(미러 포함)이고, **각각 다른 균형**을 가진다.
그 위에 Bo3의 **전략 덱 교체**가 또 하나의 게임을 이룬다 — 라운드 사이에 무엇을 바꿔 넣을지에도 균형이 있다.

→ 「호박옥은 벽 덱이다」 같은 전역 결론은 존재하지 않는다. 「호박옥 vs 던전마스터에서는 벽」,
「호박옥 vs 세제에서는 공격」처럼 **매치업별로** 나온다.

## 3. 복기 출력 규칙 — 사후편향 금지

판단의 질과 결과의 질을 분리한다.

> ❌ 「상대가 황금봉랍을 들고 있었으니 B를 뒀어야 했다」 — 둘 때는 몰랐던 정보다
> ✅ 「그 시점의 정보로는 A가 최선이었다(62%). 상대가 황금봉랍을 들고 있을 확률 34%를 감안해도 A의 기댓값이 높았다.
>    실제로 있었던 것은 운이지 판단 착오가 아니다」

복기는 **그 시점의 belief로만** 평가한다. 결과를 알고 나서 거꾸로 채점하지 않는다.
이 규칙을 어기면 틀린 것을 가르치는 도구가 된다.

## 4. 4단계가 요구하는 것 — 엔진 속도

CFR류(MCCFR · Deep CFR)는 **수천만 ~ 수억 국면**을 샘플링한다. 병목은 신경망이 아니라
**엔진이 한 판을 돌리는 속도**다.

- **8GB VRAM은 제약이 아니다.** 표 기반 CFR은 CPU · RAM 바운드이고, Deep CFR의 신경망도 작다
- 진짜 제약은 **초당 시뮬레이션 수**다. 파이썬 엔진을 평범하게 짜면 여기서 막힌다
- → **상태 모델 설계부터 속도를 전제로 한다**: 상태 복제 비용 최소화, 합법수 생성이 핫 패스,
  객체 생성 남발 금지, 되돌리기(undo) 가능한 수 적용 고려
- 초안 단계에서 **측정 가능한 형태**로 둔다 (벤치마크 스크립트를 함께 만든다)

### 마인드맵이 곧 추상화다

CFR을 실제 TCG에 그대로 돌리는 것은 불가능하다. 표준 해법은 **추상화 + 부분게임 해결**이고,
**마인드맵이 바로 그 추상화 역할**을 한다. 후보를 5개로 줄이면 CFR이 풀어야 할 게임이 작아진다.

즉 1단계의 맵은 4단계로 가는 우회로가 아니라 **전제 조건**이다.

## 5. 단계 진입 조건

```
1 → 2   엔진 규칙 정확도 확보 + belief 계산 구현
2 → 3   자가대전 로그 축적 (상대 성향 통계)
3 → 4   엔진 속도 확보 + 맵(추상화) 안정화 + 침묵률 게이트 통과
```

4단계는 두 덱이 완전히 돌아간 뒤에 **그 두 덱의 매치업 하나**에서 먼저 시도한다.
66 매치업 전체를 한꺼번에 풀지 않는다.
