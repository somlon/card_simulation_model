# 룰 정리 — 정본 룰지(2026-10-23 판) 전면 재독 (2026-10-29)

사용자 지시("카드랑 룰지를 다시 읽고, 정리한 후에, 문제가 있는 부분이 있다면 올려라")로
룰지 전문과 재정 148건(`rules/원본/재정_질문_답변_정리_2026-10-24.txt`)을 처음부터 다시
읽고 정리한 문서다. **룰지가 정본, 재정은 참고. 어긋나면 룰지가 이긴다.**

## 1. 게임 뼈대 한눈에

- **이김** (4장): ⓐ 상대 HP 0 ⓑ 상대가 덱이 비어 일반 드로우/효과 처리를 못 함 ⓒ 특수승리.
  승점 2점 선취, 라운드 사이 전략 덱 교체.
- **턴** (3장): 준비(1드로우, 첫 턴 제외) → 진행(소환·발동·로드) → 전투 → 정비(효과
  소환·로드) → 종료(턴 종료 효과 → 패 7장 버림 → 만료 → 넘김).
- **존** (0장): 유닛 5 · 이펙트 5 · 필드 1(공유) · 공유 1(마커) · 스킬 · 아카이브(공개) ·
  공허(공개) · 메인 덱(20~40) · 상급 덱(0~20).
- **유닛을 내는 길** (3-2): 소환(1턴 1번, 레벨 5+는 계승) / 효과 소환(무제한).
  계승은 효과도 파괴도 아니다.
- **전역 규칙** (1장): 모든 효과는 1턴에 1번(재정 G3 — **같은 이름 단위**).
  룰지와 카드가 충돌하면 카드가 이긴다.
- **키워드** (5장): [신속](상대 턴 가능, 이펙트는 로드 필요) [소환] [유언] [지속](선언
  없음) [전투](전투로 파괴했을 때) [트리거](그 외 조건) + [제약](소환 조건, 재정
  10-22 지시 — 패·덱·묘지에서도 판정).

## 4. 재독에서 찾은 것

### 가. 이번에 고친 구멍 (2026-10-29, 헤아림 플레이어가 드러냄)

1. **[유언] 효과가 1턴 1번을 영영 안 받았다** — `수_적용`·`턴제한통과` 둘 다
   아카이브를 안 봐서 사용 횟수가 안 올라갔다/안 읽혔다. 같은 [유언] 무한 발동 가능
   (시드 5, 잔편 2번). 고침.
2. **재정 G3 「같은 이름 단위」 위반** — 같은 카드 여러 장(10-28 허용)이면 장마다 1턴
   1번이 따로 돌았다. 전 존 같은 이름 합산으로 고침.

### 나. 룰지 문면의 중의성 — 재정질문으로 올림

- **0-5 공유 존 마커 페널티** — "마커가 뒤집힐 때 기존의 주인에게 적용" 아래 항목이
  셋(패 1장 무작위 덱으로 / 상대가 필드 카드 1장 골라 덱으로 / 1500 대미지)인데
  **셋 전부인지 택1인지, 택1이면 누가 고르는지**가 안 적혀 있다. → `재정질문/016`.
  (부수: 엔진은 마커 뒤집기만 있고 페널티 자체가 미구현 — 지금 카드 풀에 공유 존에
  유닛을 놓는 카드가 없어 실행 경로가 없지만, 생기면 바로 밟는 자리다.)

### 다. 현행 룰지에 없는데 재정에만 있는 것 (룰지 보강 후보 — 지시가 아니라 보고)

- **동시 발동의 처리 순서** — 룰지 3-6 b 는 선언 순서(턴 플레이어 우선, [트리거]·[소환]·
  [유언] 우선 선언)만 적고, **처리 순서는 재정 G1(나중 선언부터 — 옛 체인 역순)에만**
  있다. 체인·우선권이라는 말 자체가 현행 룰지에 없어, 무효·치환 계열(재정질문 014)을
  열려면 이 조항의 현행화가 선행돼야 한다.
- **멀리건 상세** (2-2) — "1회에 한해 되돌리고 다시 뽑기"의 공개 여부·순서는 룰지에
  없고 엔진도 멀리건 자체를 아직 안 둔다(`engine/deck.py` 머리 주석).

### 라. 알면서 안 하는 것 (범위 밖 — 한곳에 모아 둠)

전략 덱·라운드 진행·승점(4장 뒷부분), 멀리건(2-2), 특수승리 ⓒ(해당 카드 없음),
공유 존 배치(해당 카드 없음 — legalmoves 주석 2026-10-25). 각자 코드 주석에 사유가
있고, 여기 모은 것은 "잊은 게 아니라 안 하는 것"임을 한눈에 보이게 하려는 것이다.
