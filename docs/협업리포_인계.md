## 언제

`docs/완성_기준.md` 의 **일곱 항목이 전부 통과한 직후**, 9덱 확장을 시작하기 **전에** 한 번 한다.
확장분은 나중에 같은 방식으로 **새 브랜치를 또 하나** 만들어 올린다(기존 브랜치를 갈아 끼우지 않는다).

## 절대 하지 말 것 — 하나라도 어기면 중단하고 `진행.md` 에 기록만 한다

- `main` · `default` 에 푸시 금지
- 계열 기준 브랜치(`model/main` · `data/main` · `docs/main` · `analysis/main` · `exp/main`)에
  **직접** 푸시 금지. 그것들은 **베이스로만** 쓴다
- `--force` · `--force-with-lease` · `push -f` 금지. 어떤 상황에서도
- 그 리포의 **기존 파일을 수정하거나 삭제하지 않는다.** 새 폴더에 새 파일만 더한다
  (아래 4번의 검증이 이것을 기계로 확인한다)
- PR을 만들더라도 **머지하지 않는다.** 머지는 리포 주인의 몫이다
- 브랜치를 **지우지 않는다**(이미 있으면 이름 뒤에 `-2` 를 붙여 새로 만든다)

## 절차

```sh
# 1. 베이스는 model 계열 기준 브랜치. 코드가 주 산출물이므로 model 계열이 맞다.
git clone --branch model/main --single-branch \
  https://github.com/somlon/card_simulation_model.git /tmp/sim
cd /tmp/sim
git switch -c model/card_ai-1층필터-20261025      # 이미 있으면 뒤에 -2

# 2. 겹치지 않는 새 폴더 하나에만 담는다. 이것이 「덮어쓰기 아님」의 보증이다.
mkdir -p card_ai_1층필터
# card_ai 리포에서 그대로 복사: engine/ tests/ scripts/ maps/ docs/ data/수입분류.json
#   requirements.txt README 는 card_ai_1층필터/ 안에 둔다. 루트에 두면 기존 파일과 충돌한다.
#   data/card_pool.json 은 그 리포에도 있으니 복사하지 않는다 — 출처가 갈라지면 안 된다.

# 3. 무엇을 왜 올렸는지 적은 안내문을 폴더 루트에 둔다
#    card_ai_1층필터/README.md — 1층 필터가 무엇이고 무엇이 아직 없는지(합법수 생성 범위,
#    미해결 항목), 돌리는 명령, 그리고 nny_sim 과의 관계(아직 합치지 않았다는 것)

# 4. 추가만 했는지 기계로 검증한다. A(추가) 이외의 상태가 하나라도 나오면 중단한다.
git add -A
git diff --cached --name-status | grep -v '^A' && echo "중단: 추가 외의 변경이 있다" && exit 1

git commit -m "card_ai 1층 맵 필터 인계 — card_ai_1층필터/ 추가 (기존 파일 무변경)"
git push origin model/card_ai-1층필터-20261025      # -u 도 -f 도 쓰지 않는다

# 5. 올라갔는지 확인한다
git ls-remote --heads origin | grep card_ai-1층필터
```
