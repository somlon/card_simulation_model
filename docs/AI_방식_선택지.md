# AI를 「사람같이 + 잘 두게」 만드는 방식 — 세창 선택 대기

장인준 구상(2026-10-30) 3안. **각 안의 실행 가능한 데모가 `nny_sim/online_demos/` 에 있다**
— 돌려보고 마음에 드는 방향(또는 조합·순서)을 고르면 그쪽으로 본격 구현한다.

## 1안 「한 판 전수 복기」 — demo_방식1_복기.py

사람vsAI 한 판이 끝나면, 그 판의 분기점들을 **미래를 모른다는 전제**로 다시 돌려(롤아웃)
"가장 좋았던 수 / 수비적인 수"의 순위를 매기고, 실제 선택과 비교해 판단 가중치를 보정한다.
마작 타패 순위처럼 「이 상황 1순위/2순위 수」를 그 한 판에서 뽑아내는 방식.
- 장점: 기보 데이터가 없어도 됨. 판마다 깊게 배움.
- 유의: 한 판의 모든 경우의 수는 폭발하므로 분기점 샘플링 + 롤아웃 근사로 돌린다.

## 2안 「사람 로그 모방」 — demo_방식2_모방.py

매치에서 **사람이 어떤 상황에서 어떤 수를 골랐는지** 로그를 모아, 같은 상황에서 사람의
선택을 따라하도록 학습한다. "사람같이"의 정공법이고 신경망으로 확장이 가장 자연스럽다.
- 장점: 사람다움이 직접 목표가 됨 (측정 = 사람 수 일치율).
- 유의: 기보 통계가 많이 필요 — 온라인판 기보 수집(⑥)이 공급선.

## 3안 「AI 자기대전 가치 지도」 — demo_방식3_가치지도.py

AIvsAI를 대량으로 돌려 **카드별 킬 루트·특수소환 루트의 마인드맵(콤보 그래프)**을 만들고,
행동마다 리턴 +x / 리스크 -x 수치를 산출해 리스크-리턴 계산으로 두게 한다.
- 장점: 덱 수가 적어 빨리 수렴 가능. 사람 데이터 불필요. 심리적 요소(위험 감수 성향)를
  수치로 조절 가능.
- 유의: "사람같음"은 따로 안 생김 — 1·2안과 조합할 때 완성됨.

## 참고 (조합 제안)

셋은 배타적이 아니다. 추천 순서: **3안(가치 지도 — 기반) → 1안(판마다 복기 보정) →
2안(기보 쌓이면 사람 앵커)**. 신경망은 어느 안의 데이터로도 이행 가능하며, 학습 계산은
장인준 PC(RTX 8GB — 이 규모엔 충분)나 Kaggle 무료 GPU(주 30시간)에서 하고 결과
모델·표 파일만 리포에 올린다. 게임 실행 중에 LLM은 쓰지 않는다(느리고 비싸고 불필요).
